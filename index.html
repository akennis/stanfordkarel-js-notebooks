An introduction to programming

Learning JavaScript with Karel

Ten short, notebook-style lessons that teach the fundamentals of JavaScript by programming a friendly robot named Karel.

No setup required. Every lesson mixes plain-English explanations with real JavaScript code, and each snippet is brought to life as an animated Karel program right on the page. Work through them in order — each builds on the one before.

The course

  1. Commands & Sequencing
    Programs are lists of commands that run in order.
  2. Functions
    Bundle commands into reusable, named building blocks.
  3. The for Loop
    Repeat something a fixed number of times.
  4. The while Loop
    Repeat until a condition changes.
  5. Making Decisions with if
    Booleans, and running code only when a condition holds.
  6. if / else
    Choose between two different actions.
  7. Parameters
    Functions that take input and adapt their behaviour.
  8. Variables
    Give a program a memory: store, read, and update values.
  9. Return Values & Logic
    Functions that answer questions; and / or / not.
  10. Putting It All Together
    Nested loops and every concept, in one program.
