Assignments

Graded exercises. Solve each one, check it against the goal, then submit your code.

There is one assignment per lesson, each with three problems — simple, moderate, and complex. Every problem gives you a goal animation and an editable code box, just like the lesson challenges. The green ✓ is a practice check — your grade comes from the single submission you copy from the bottom of the page and your instructor re-runs.

How to submit

Submit with git (preferred):

  1. Create a repository from your instructor's assignments template.
  2. On each assignment page, press 📋 Copy submission.
  3. Save the copied text as submissions/<assignment-id>.js in your repo.
  4. git add, git commit, and git push.

No git? Paste the same text into your shared Google Doc under a heading matching the assignment id.
