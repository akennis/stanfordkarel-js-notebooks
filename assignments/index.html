How to submit

Submit with git (preferred):

  1. Create a repository from your instructor's assignments template.
  2. On each assignment page, press 📋 Copy submission.
  3. Save the copied text as submissions/<assignment-id>.js in your repo.
  4. git add, git commit, and git push.

No git? Paste the same text into your shared Google Doc under a heading matching the assignment id.
