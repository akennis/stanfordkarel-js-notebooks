    Quick reference — world format & Karel commands
    
Full details of every syntax are on the World Formats page (opens in a new tab). Two legacy formats are auto-converted on load, so you can paste any of these styles:

    
    
      
  • the lowercase KarelWorld format (streets/avenues/eastwestwalls/northsouthwalls/beepers) — if a wall lands one cell off, flip EW_SIDE/NS_SIDE in the page source;
    • 
      
  • the colon-delimited, 0-indexed format (dimension:4:7, karel:2:1, top/bottom/left/right:a:s, beeper:a:s).
    • 
    

    
World file format (one directive per line, 1-indexed from the bottom-left corner):


Dimension: (avenues, streets)      # grid width × height
Karel: (avenue, street); direction # start pose — direction is north/south/east/west
BeeperBag: n                       # starting beepers (a number or INFINITY)
Beeper: (avenue, street); count    # beepers on a corner
Wall: (avenue, street); direction  # wall on that side of the corner
Color: (avenue, street); colorName # painted corner (e.g. Red, Blue)
Speed: n                           # animation speed (float)

    
Karel commands — call them on the k passed to main(k):

    

      
k.move()Move one corner forward.

      
k.turnLeft()Turn 90° left (there is no turnRight — turn left three times).

      
k.putBeeper()Drop a beeper on the current corner.

      
k.pickBeeper()Pick up a beeper from the current corner.

      
k.paintCorner(color)Paint the current corner (e.g. "Red").

      
k.frontIsClear()→ boolean: no wall ahead.

      
k.leftIsClear() / k.rightIsClear()→ boolean: no wall to the side.

      
k.beepersPresent()→ boolean: a beeper is on this corner.

      
k.beepersInBag()→ boolean: Karel is carrying beepers.

      
k.facingNorth() / South / East / West→ boolean: current direction.
