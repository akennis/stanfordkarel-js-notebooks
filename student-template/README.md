# Karel Assignments — my submissions

This is your personal repository for submitting Karel assignments. Your instructor
grades the code you push here.

## Setup (once)

1. Create your own repository from this template (on GitHub: **Use this template →
   Create a new repository**), or copy this folder into a new repo.
2. Fill in `student.json` with your name and GitHub username.
3. Give your instructor the repository URL (they add it to their roster).

## Submitting an assignment

1. Open the assignment page (your instructor will link it), e.g.
   `.../assignments/assignment.html?id=collect-all`.
2. Write your solution in the code box and press **▶ Run** until you get the green ✓.
3. Press **📋 Copy submission**.
4. Save the copied text as `submissions/<assignment-id>.js` in this repo — the id is
   shown on the page (for example `submissions/collect-all.js`).
5. Commit and push:

   ```bash
   git add submissions/
   git commit -m "Submit collect-all"
   git push
   ```

Re-submitting is just editing the same file and pushing again — your instructor
grades the latest version.

## Rules

- **Keep the header comment lines** at the top of each submission file. They tell the
  grader which assignment the file answers.
- One file per assignment, named exactly `submissions/<assignment-id>.js`.
- Don't edit files outside `submissions/`.

## No git?

If you can't use git, paste the same copied text into the shared Google Doc your
instructor set up, under a heading that matches the assignment id.
