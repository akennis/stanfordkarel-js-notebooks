Karel Reference

One page per command and condition — each with a simple example, a complex example, and two challenges to try.

Every operation and condition Karel understands has its own page below. Each page shows a worked simple example and a complex example (code plus a live animation and an explanation), then hands you a trivial and a complex challenge to solve in an editable code box. Reach for these when you want to look up exactly what one command does.

Commands — things Karel does

  • k.move()
    Step one square forward.
  • k.turnLeft()
    Rotate 90° to the left.
  • k.putBeeper()
    Drop a beeper from the bag.
  • k.pickBeeper()
    Pick a beeper up into the bag.
  • k.paintCorner(color)
    Paint the current corner a color.

Conditions — things Karel can sense

  • k.frontIsClear()
    Is the way ahead open? (and frontIsBlocked)
  • k.leftIsClear()
    Is the square to the left open? (and leftIsBlocked)
  • k.rightIsClear()
    Is the square to the right open? (and rightIsBlocked)
  • k.beepersPresent()
    Any beepers on this corner? (and noBeepersPresent)
  • k.beepersInBag()
    Any beepers left in the bag? (and noBeepersInBag)
  • k.facingNorth()
    Is Karel facing north? (and notFacingNorth)
  • k.facingEast()
    Is Karel facing east? (and notFacingEast)
  • k.facingSouth()
    Is Karel facing south? (and notFacingSouth)
  • k.facingWest()
    Is Karel facing west? (and notFacingWest)
  • k.cornerColorIs(color)
    Is this corner painted a given color?
