Karel World Formats

How a Karel world is written down — the native format the library reads, and two alternative syntaxes the Playground understands.

A “world” is just plain text describing the grid: how big it is, where Karel starts, and where the beepers, walls, and paint are. The library (runKarel) reads exactly one format — the native .w format below. The Playground additionally auto-detects and converts two alternative formats into .w so you can paste worlds exported by other Karel tools. If you call the library directly, convert to .w first.

Coordinate system (shared by every format)

  • Avenues are columns (x, run north–south); streets are rows (y, run east–west).
  • Corners are counted from the south-west. In the native format they are 1-indexed, so (1, 1) is the bottom-left corner.
  • Directions are the lowercase words north, south, east, west.

The native .w formatRead by the library

One directive per line, Keyword: value. This is the same plain-text format used by the Python Stanford Karel. Unrecognized lines and blank lines are ignored; a line needs a colon to be read at all.

DirectiveMeaning
Dimension: (a, s)Grid size: a avenues wide, s streets tall.
Karel: (a, s); dirStart corner and facing (north/south/east/west).
BeeperBag: nBeepers Karel starts with. Use INFINITY for an unlimited bag.
Beeper: (a, s); nPlace n beepers on a corner. Repeated lines add up.
Wall: (a, s); dirA wall on the dir side of corner (a, s).
Color: (a, s); namePaint a corner. name is a named color (e.g. Red, Blue), not a hex value.
Speed: nAnimation speed (a positive number; higher is faster).

Example

Dimension: (5, 5)
Karel: (1, 1); east
BeeperBag: INFINITY
Beeper: (3, 3); 2
Wall: (2, 1); north
Color: (4, 4); Blue
Speed: 3

Edge convention. Whether an eastwestwalls/northsouthwalls line sits on the north/south (or east/west) side of a corner varies between tools. The Playground assumes north and east; if a converted wall lands one cell off, flip EW_SIDE/NS_SIDE near the top of the Playground’s script.

Alternative: the colon-delimited formatPlayground only

A compact keyword:a:b style. Its coordinates are 0-indexed from the bottom-left, so the Playground adds 1 to every avenue and street when converting (the dimension line is a pair of counts, so it is left as-is).
